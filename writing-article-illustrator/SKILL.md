# 文章配图与视觉素材

配图服务于理解、记忆和节奏，不是把每个段落机械配一张图。先确定图片承担的阅读任务，再决定检索、生成或不配图。

## 输入检查

读取最终稿或 `revised-draft.md`，同时加载 `style-rules.json/style-guide.md`。先建立六格需求卡，确认：

- 平台、画布比例、输出格式、图片数量上限和是否需要文字入图。
- 品牌色、视觉风格、禁用元素、人物/Logo/版权要求。
- 图片来源策略：用户提供、可检索素材、AI 生成或仅输出占位符。
- 交付形式：图片清单、Markdown、图片文件或供平台排版 Skill 引用的视觉资产。

读取本技能的 `EXTEND.md` 选择平台配置；用户明确指定的配置优先于默认值。

## 工作流程

1. 标记文章中的信息节点：封面/首图、概念解释、数据对比、步骤流程、案例场景、转折和结尾。每个节点判断“配图能否增加理解”，不能增加时不配图。
2. 生成图片清单，每张图分配 `IMAGE-01` 等稳定 ID，并写清位置、目的、画面、构图、主体、色彩、比例、文字安全区、alt 文本和版权来源。
3. 为需要生成的图片编写提示词：主体 + 场景 + 构图 + 视觉风格 + 色板 + 镜头/质感 + 比例 + 负面约束。不要把大段正文直接塞进图片提示词。
4. 如果调用图片生成工具，逐张生成并人工确认；不满意时只重做该张，不默认整批推翻。若调用检索工具，保存来源 URL、许可、作者和下载日期。
5. 在正文中插入 `<!-- IMAGE-XX -->`，给每张图配可访问的 alt 文本和图注；不把未生成的图片伪装成已存在文件。
6. 按平台输出：默认交付 `image-brief.md` 和确认后的 `images/`；正文 HTML、富文本或 Word 版式交给 `writing-platform-layout` 或文档 Skill 处理。

## 产物契约

`image-brief.md` 至少包含：

- 平台配置与总览
- 图片清单：ID、位置、目的、比例、尺寸、类型、提示词、alt、图注、状态
- 文章插图标记版
- 版权/来源登记和人工确认点
- 若图片未生成，列出后续动作而不是伪造文件路径

图片文件推荐放在用户指定的 `images/` 目录，使用 `IMAGE-XX` 命名；HTML 用相对路径，目标编辑器要求内嵌时才转为 base64。禁止默认引用不稳定的远程图片 URL。

## 质量门禁

- [ ] 图片数量与阅读节奏匹配，封面、正文和结尾有明确分工。
- [ ] 比例、尺寸、色彩和风格与平台/品牌要求一致。
- [ ] 图片中的文字少且可读，关键内容不会被裁切。
- [ ] 每张图有 alt 文本、图注或明确“不需要图注”。
- [ ] 每个外部图片有来源和许可记录；AI 生成图标明生成方式。
- [ ] 图片文件名、路径、比例、alt、图注和来源已经检查，并能被 `writing-platform-layout` 稳定引用。
