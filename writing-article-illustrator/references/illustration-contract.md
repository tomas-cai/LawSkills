# 图片清单与排版契约

## 单张图片字段

```markdown
### IMAGE-01
- 位置：导语之后
- 阅读目的：把抽象概念变成一眼可懂的关系图
- 类型：生成 / 检索 / 用户提供 / 不配图
- 比例与尺寸：
- 画面描述：
- 提示词：
- 负面约束：
- alt：
- 图注：
- 来源与许可：
- 状态：待确认 / 已生成 / 已替换 / 已嵌入
```

## 占位标记

正文中使用 `<!-- IMAGE-01 -->`，不要写入不存在的文件路径。最终 HTML 可将其替换为 `<figure>`，并保留 `alt`、图注和来源信息。

## 配图判断

适合配图：结构关系、流程、对比、数据趋势、场景氛围、章节转折。通常不需要配图：仅为装饰的重复插图、无法确认版权的网络图片、会泄露敏感信息的截图。
