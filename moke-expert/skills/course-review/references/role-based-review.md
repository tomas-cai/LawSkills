# 角色 × 层级评审判据卡（维度 10 专用）

> 适用：`course-review` 维度 10。评审对象为 **M / L 档培训项目** 及其课程材料；S 档按 §1.3 精简。
> 版本：1.10.0 新增（`course-review` 技能自身 v1.6.0）。闭合缺陷 **G-21 评审判据代际滞后** / **G-22 名称漂移**。
> 前置：`course-design/references/structure-levels.md`（L0-L6 层级）、`course-design/references/roles-and-stages.md`（RACI 与能力栈）、`course-design/references/program-structure.md`（三张卡与五模式）。

---

## §0 本文件解决什么

1.6~1.9 把「阶段归属 / 结构模式 / 层级契约 / 角色模型」全部写进了规范层，但评审技能仍停在 1.5.0：**16 个关键概念在评审判据里 0 命中**（见 `QUALITY-REVIEW.md` §2 证据 5）。结果是「规范说不能跨阶段，评审却只查文件齐不齐」。

> **一句话判据（V-8）**：`规范写了 ≠ 评审查得出`。规范层每升一代，评审技能须同步补判据，并复测概念命中；否则**不得声称本包能防住该代缺陷**。

本文件把 `roles-and-stages.md` §3 的四角色能力栈**翻译成评审动作**：每条判据都给「查什么 / 怎么取证 / 什么算不合格 / 对应哪条缺陷」，评审者照表勾选即可。

## §1 使用规则（先于任何评分）

### §1.1 评审前换帽声明（必写）

```
【评审换帽】本轮按四角色分别评审，判据不互相顶替。
规模档：S / M / L（依据：出口绩效是否含「在岗独立完成」）
本轮启用卡：A 项目设计师 / B 课程设计师 / C 磨课师 / D 体系架构师（仅 L 档）
```

⛔ 不写这句、或四层共用一个总分 → 判 **视角未切换（V-7）**，维度 10 记 0 分。

### §1.2 三条硬约束

| # | 约束 | 违反后果 |
|:---:|:---|:---|
| 1 | **四层独立给分**，各 /5，**不得求平均**，不得用「总体 4/5」掩盖某一层 P0 | 维度 10 结论无效，重写 |
| 2 | **任一层出现 P0 → 整体不予通过**，与其他层得分无关 | 交付门禁（见 `course-design/SKILL.md` Phase 03） |
| 3 | 每条判据须给**计数或命中位置**；⛔ 不得写「已检查 / 基本一致」 | 取证不完整，该项按未过计 |

### §1.3 规模分档（防过度工程）

| 档 | 启用卡 | 可省略 |
|:---:|:---|:---|
| **S 单课**（≤2 天、无客户现场、无答辩） | B + C（各取前 3 条） | A / D 全免；不查 6Ds、不查认证蓝图 |
| **M 多天项目**（≥2 天，或含实战 / 客户现场 / 答辩） | **A + B + C 全卡** + §3 交叉检查 | D 标 N/A |
| **L 体系**（≥3 门课且有进阶关系） | **A + B + C + D 全卡** | 无省略 |

> ⛔ 把 S 档当 M 档跑 = 过度工程；把 M 档当 S 档跑 = 5 天项目按「几门课拼起来」评，正是 G-16 / G-18 的成因。

## §2 四张判据卡

### 卡 A · 项目设计师（L2）— 评「这次干预排得对不对」

| # | 判据 | 取证方式 | 不合格判据 | 缺陷 |
|:---:|:---|:---|:---|:---:|
| A1 | **三张前置卡齐备**：出口绩效 / 任务清单 / 学员起点，且出口绩效含「产出物 / 完成条件 / ≥3 条可观测判据 / 验收人 / 独立度」 | 逐卡数条目，给「齐 / 缺 / 半」分布 | 缺任一卡；目标写成「了解 / 掌握 / 熟悉」 | G-17 |
| A2 | **任务清单标了「是否可培训」**：频率 × 关键性 × 难度 × 可培训性四列齐；不可培训项只教识别与转交 | 数清单行与标了可培训性的行数 | 出现「无权限 / 无接口 / 低频高风险」任务被当技能教 | G-19 |
| A3 | **结构模式显式选型且给依据**：写明 P1~P5 中哪一个 + 判别矩阵中定案的那一问 | 检索模式词与「第几问」，给命中位置 | 沿用上一版排法；答不出哪一问 → 标「假设版结构」 | G-16 / G-17 |
| A4 | **阶段归属矩阵跨阶段行 = 0**：每个单元只标称 1 个阶段，「活动 → 模块 → 阶段」三列齐 | 逐行数单元与跨阶段行，给计数 | 跨阶段行 >0；或把「分钟合计相等」当分段正确 | G-14 / G-15 |
| A5 | **时长依权重不均分**：各段时长有依据，非三段等分；实施段权重与出口绩效匹配 | 列时长表（段 × 分钟 × 占比 × 依据） | 默认均分且无依据 | G-15 |
| A6 | **6Ds 六格全有内容**，且 D4「推动转化」责任人**不是讲师**；转化气候有 ≥2 条组织侧动作 | 逐格填「有 / 空」，查 D4 责任人字段 | 把「课中」删掉后方案剩不到一半；D4 挂在讲师名下 | G-19 |
| A7 | **评估四层可观测**：L3 行为有观测方式与观测人；L4 只承诺可归因部分 | 查评估方案 L1-L4 条目 | 只有 L1 满意度 | G-17 |
| A8 | **商业约束与最优方案分离**：连排 / 客户不到场等妥协须写明「被放弃的更优方案 + 理由」 | 检索「假设版 / 商业约束 / 被放弃」 | 把妥协包装成「最佳实践」 | G-17 |

> **卡 A 头号失败**：只设计课中。判据一句话：**把「课中」从方案里删掉，剩不到一半，就还是课表。**

### 卡 B · 课程设计师（L3）— 评「这门课分得对不对」

| # | 判据 | 取证方式 | 不合格判据 | 缺陷 |
|:---:|:---|:---|:---|:---:|
| B1 | **逆向设计**：每个模块先有评估证据，且证据形态 = 真实产出物（非选择题） | 数模块数与有证据的模块数 | 先排活动再补目标 | G-19 |
| B2 | **整体任务 + 支架递减**：学员首次见完整链路**不晚于倒数第二个单元**；支架逐轮撤除有记录 | 给「首次见全链路单元序号 / 总单元数」 | part-task 碎片序列；到最后一个单元才见全貌 | G-16 |
| B3 | **首要教学原理五要素**：问题中心 / 激活 / 示范 / 应用 / 整合；「示范」须展示怎么做 | 逐模块勾五要素，给缺口数 | 只有「讲 + 练」，无示范无整合 | G-19 |
| B4 | **活动可删性**：任一活动删掉后出口绩效判据仍能达成 → 应删 | 抽 3 个活动做反事实检查，给结论 | 活动导向（热闹但不指向出口绩效） | G-19 |
| B5 | **目标-内容-测评对齐**：每条 OBJ 有对应 ASSESS，且达成度可回查 | 列 OBJ × ASSESS 矩阵，数孤儿 | 有 OBJ 无测评 | 维度 2 |
| B6 | **层级声明**：课程设计文档标题带 L3 标签；全文无「课程体系」误用（除非 L 档） | 检索层级标签与「体系」出现位置 | 用 L3 模块去填 L2 天数 | G-18 |

> **卡 B 头号失败**：把不可培训的任务当技能教（与 A2 联动反查任务清单）。

### 卡 C · 讲师／磨课师（L4-L5）— 评「这一节课讲不讲得下来」

| # | 判据 | 取证方式 | 不合格判据 | 缺陷 |
|:---:|:---|:---|:---|:---:|
| C1 | **分钟轴可加总**：段时间合计 = 总时长；页内 steps 合计 = 页 minutes | 给时长表（页 × 步骤合计 × 页 minutes） | 差 1 分钟也算不符 | G-7 |
| C2 | **逐页讲解层齐备**：每页有逐字话术 / 提问 / 互动 / 应急，非元数据面板 | 抽查首 / 中 / 末页，给覆盖率 | 讲师视图只有页码与要点条数 | G-4 / G-5 |
| C3 | **工具卡五点闭环**：定义 → 发放 → 上屏可数 → 对手戏 → 实物；数量宣称 = 编号数 | 给五点清点矩阵 + 悬空引用清单 | 悬空落点（含讲师兜底语）→ **P0** | G-10~G-12 |
| C4 | **润色不改内容**：润色版未改变任何学习目标或考核判据 | 逐条比对目标与判据文本 | 借润色改目标 → 退回课程设计师 | G-19 |
| C5 | **上屏纪律**：单页一个核心结论、不念屏、字不叠图；标题合格率 100% | 给正向内容验收 7 项分布 | 只跑负向禁词表就判通过 | G-4 / G-5 |
| C6 | **降级预案**：每个长活动有「超时 10 分钟」降级路径；≥3 条兜底话术落字 | 数长活动数与有预案数 | 只有 Plan A | 维度 5 |

> **卡 C 头号失败**：把润色做成改内容；以及「形式全通过、上屏没内容」。

### 卡 D · 体系架构师（L1，仅 L 档）— 评「要不要升级成体系」

| # | 判据 | 取证方式 | 不合格判据 |
|:---:|:---|:---|:---|
| D1 | 满足启用门槛：**≥3 门课且有进阶关系（含认证 / 复训）** | 数课程数与阶梯层级 | 单项目里给该角色主责 = 过度设计 |
| D2 | 先修关系无环，每门课写明「前置课 / 无前置」 | 画依赖图查环 | 全部无前置 → 其实是并列，不是体系 |
| D3 | 认证蓝图权重合计 100% 且来源可追溯（任务频率或风险） | 加总权重 | 权重均分 |
| D4 | 每级有独立出口绩效，「高级 ≠ 初级内容更多」 | 逐级比对出口绩效 | 分级只靠课时长短 |

> ⛔ **S / M 档卡 D 一律标 N/A，不计分、不判缺陷**。

|:---:|:---|:---|:---|

| X4 | **层级标签**：结构类文档标题带 L1-L4 标签；无跨层造词（「培训项目课程体系」） | 检索标题与跨层词 | 一章内混用 6Ds 与 Gagné |
| X5 | **证据等级标注**：`[证据] / [惯例] / [结构]` 标注齐全；`[惯例]` 未被写成「被证明」 | 数标注数与误用数 | BOPPPS / 70-20-10 被称实证 |

## §4 概念命中复测（防代际滞后，每次规范升级后必跑）

规范层每升一代，按下表对 `course-review/SKILL.md` 与 `references/review-methodology.md` 复测；**任一新增概念 0 命中即判 G-21 复发**：

```
四角色 / 角色失配 / 结构模式 / 阶段归属 / program-design / 6Ds / RACI /
判据不互替 / 假设版结构 / 回接 / 证据等级 / G-14 / G-16 / G-18 / G-19 / G-20 / G-21 / G-22
```

复测须给「概念 × SKILL 命中数 × METH 命中数」矩阵，**0 命中概念数必须为 0**。整改前基线（见 `QUALITY-REVIEW.md` §2 证据 5）：**16 个概念全部 0 命中**；本表在该基线之上补充 G-21 / G-22，扩至 18 词。

## §5 评分与报告口径

- 报告「总体评估」须列：`项目架构 /5 ｜ 课程设计 /5 ｜ 课堂落地 /5 ｜ 体系适配 /5（S/M 档标 N/A）`
- 「各维度发现」维度 10 须给：四张卡**逐条命中数**（如 A 卡 8 条过 6 条，列未过 2 条）、X1-X6 计数、概念命中矩阵
- ⛔ 不得把四层合并成一个「结构 4/5」；⛔ 不得用维度 1-9 的高分抵消维度 10 的 P0
- 任一层 P0 → 报告结论写「**不予交付**」，并写明是哪一层的哪条判据

## §6 边界与失效条件

| 边界 | 说明 |
|:---|:---|
| `规范写了 ≠ 评审查得出`（V-8） | 本卡只保证「有判据可勾」，不保证评审者判断正确 |
| `评审通过 ≠ 结构正确` | 判据依赖材料自述，仍须真人试讲与真实任务数据校验 |
| `角色齐备 ≠ 视角真切换`（V-7） | 四张卡都在而共用一个总分 = 未分化 |
| `技能顶尖 ≠ 场景适配` | 4C/ID 用在 60 分钟合规课、6Ds 用在单课上都是过度设计；按 S/M/L 裁剪 |
| 与维度 9 的分工 | 维度 9 查「课件上屏内容」，本维度查「谁在做、按哪层判据、有无越界」；⛔ 不重复评上屏文案 |
