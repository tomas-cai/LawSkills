# 案例结构与示例

## 单案例文档结构

每个案例单独保存为一个 Markdown 文档，不合并到总文档。

文件命名：`{价值观维度}-{标题}-{分值}-{月份}.md`

示例：`成就客户-规范铁建重工项目交付标准显性化服务价值-4分-2026-04.md`

```markdown
# 规范铁建重工项目交付标准，显性化服务价值-（成就客户4分）

- 价值观维度：成就客户
- 分值：4分
- 月份：2026-04
- 客户/主题：铁建重工
- 素材来源：raw/2026年4月工作事项汇总.md

## 情景S

<背景、问题、当前处境>

## 任务T

<本次要完成的任务/目标>

## 行动A

1. <动词开头，写明行为、对象、时间>
2. <具体动作与结果>
3. <具体动作与结果>

## 结果R

<成果、反馈、成长>

## 建议S

1. <可复用、可落地的建议>
2. <可复用、可落地的建议>
3. <可复用、可落地的建议>
```

## STARS 结构

本格式为 STARS 五段式：

- S（Situation）：情景，交代背景、问题、当前处境
- T（Task/Target）：任务/目标，写明要完成什么、为谁、到什么程度
- A（Action）：行动，写我做了什么、怎么做
- R（Result）：结果，写成果、反馈与成长
- S（Suggestion）：建议，写可复用、可落地的改进建议

正文顺序固定为：情景S → 任务T → 行动A → 结果R → 建议S。

## 示例：4 分案例（成就客户）

标题：规范铁建重工项目交付标准，显性化服务价值-（成就客户4分）

情景S：铁建重工作为核心客户，4月份持续提出岗位梯队功能相关的多项需求和问题反馈，需求边界模糊，项目交付缺乏统一标准，且我方为客户提供的超纲服务未充分呈现，导致客户对我方服务价值感知不足，需规范交付标准、显性化服务价值。

任务T：在铁建重工项目沟通会议前统一交付标准，明确需求管理口径，并把超纲服务显性化同步给客户。

行动A：
1. 明确项目交付标准：在铁建重工项目沟通会议中，正式确立客户项目管理三大输出物——工单全生命周期进度表、会议纪要、对应工单的设计方案，确保项目交付规范化。
2. 细化需求管理：与凡佳樱沟通，将需求状态细化为待分析、已分析、已设计等8个类别，实现需求全流程可控，确保内部信息同步一致。
3. 显性化超纲服务：强调团队需将李建华完成的计划功能优化等超纲服务，进行可视化整理，定期同步给客户，让客户清晰感知我方额外付出。
4. 厘清需求边界：针对系统对接数据异常问题，客观澄清责任归属，明确是铁建未更新数据、我方接口正常，避免客户误解，同时指导鄢婷婷学会管理客户诉求边界。

结果R：铁建重工项目交付实现标准化、流程化，需求进度透明可控，责任划分清晰；超纲服务价值得到显性化展示，客户对我方的专业度和服务意识给予高度认可，客户沟通更加顺畅，进一步巩固了核心客户合作关系。

建议S：
1. 提前制定大客户需求边界清单，前置同步客户，减少后期需求无序新增。
2. 固化三大交付物模板，后续大客户项目直接复用，提升交付效率。
3. 按月汇总额外增值服务清单，主动同步客户，持续提升客户口碑和认可度。

## 示例：5 分案例（开放进取）

标题：积极应对晶台广电定制需求，进取推进需求评估与方案讨论-（开放进取5分）

情景S：晶台广电提出数据报表定制开发需求，该需求涉及定制化开发，需评估需求可行性、方案细节及相关费用，且客户有明确的沟通时间要求，需以开放心态面对新的定制需求，积极进取推进需求评估，确保快速响应客户诉求，拓展客户合作空间。

任务T：快速完成晶台广电数据报表定制需求评估，明确方案、费用与沟通排期，主动推动客户沟通落地。

行动A：
1. 积极对接需求：主动与陆爱沟通，详细了解晶台广电数据报表定制开发的具体需求，耐心倾听客户诉求，不回避需求中的难点，积极探讨需求可行性。
2. 进取推进评估：针对定制需求，主动梳理需求核心要点，评估开发难度、工作量及相关费用，形成初步评估思路，为后续方案讨论奠定基础。
3. 主动规划沟通：积极响应客户需求，约定举行会议讨论定制开发的具体方案、费用及推进计划，确保需求推进有明确方向，主动把控工作进度，不拖延、不推诿。

结果R：晶台广电定制需求得到快速响应，需求评估工作顺利推进，明确了会议讨论时间和核心议题；客户感受到我方积极进取、高效负责的工作态度，对后续合作充满信心；自身通过对接新的定制需求，拓展了业务思路，提升了需求评估和方案规划能力，为后续定制项目落地做好了准备。

建议S：
1. 会议前，可提前梳理定制方案的初步框架和费用测算，提高会议沟通效率，快速推进需求落地。
2. 针对定制化需求，可整理同类项目案例，借鉴经验，优化评估方法，提升评估准确性。
3. 会议后，及时整理会议纪要，明确推进节点和责任人，主动跟进方案落地，确保客户需求得到高效满足。

说明：以上示例仅示范写作口径，对应素材属于示例月份；实际使用时以当月 raw 素材为准，并通过案例登记表避免与历史案例重复。
