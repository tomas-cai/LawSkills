# 写作质检与润色量表

## 严重程度

| 级别 | 判定 | 处理 |
|---|---|---|
| P0 | 事实错误、严重误导、隐私/版权/合规风险、无法交付 | 阻断交付 |
| P1 | 主旨偏移、核心证据缺失、结构无法支撑承诺 | 回退 outline/writer |
| P2 | 明显语病、逻辑跳跃、风格或平台不一致 | 本轮修订 |
| P3 | 可读性、节奏、措辞等可选优化 | 视时间处理 |

## 报告条目

```markdown
| ID | 级别 | 位置 | 原文 | 问题 | 依据 | 建议 | 已修复 |
|---|---|---|---|---|---|---|---|
| P-01 | P1 | 第 2 节 | … | 论点缺少证据 | C02 无 evidence | 补来源或删掉该论点 | 否 |
```

## 修订边界

允许直接修正错别字、标点、冗余和不改变含义的句式；涉及数字、原话、因果、人物立场、结论或段落顺序时，必须登记为实质性修改并保留人工确认点。
