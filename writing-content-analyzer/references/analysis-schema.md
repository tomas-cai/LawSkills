# content-analysis 结构说明

## 事实状态

| 状态 | 含义 | 下游使用规则 |
|---|---|---|
| `confirmed` | 原始材料直接支持，来源可定位 | 可直接写入 |
| `reported` | 材料记录了某人/某来源的说法，但未独立核验 | 用“据某人/材料称”等归属表达 |
| `inferred` | 根据多个片段推得的解释 | 只能作为假设，不能写成事实 |
| `needs-check` | 信息不足、冲突或来源不明 | 先补证据或保留待核实标记 |

## 来源锚点

优先使用稳定锚点：

- Markdown/纯文本：`[S01:L120-L138]`
- DOCX/PDF：`[S02:p4]` 或 `[S02:p4:表1]`
- 音频/视频转录：`[S03:00:14:32-00:15:10]`
- 网页摘录：`[S04:标题/段落关键词]`

若输入无法提供行号，给出文件名、页码、段落标题或原文前 8–15 字作为定位信息。

## 论点—证据矩阵

每个可写论点至少回答：

1. 论点是什么？
2. 哪些事实/原话支持它？
3. 是否存在反例或限制条件？
4. 文章可以用什么强度的语气表达？

不允许用“素材里大概提过”替代证据 ID。
