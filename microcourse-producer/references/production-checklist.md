# 微课制作与交付检查清单

## 资源包清单

| 资源 | 必需条件 | 状态 |
|---|---|---|
| 主课件或页面 | 内容与脚本一致、手机可读 | |
| 口播稿/文字稿 | 与最终版本一致 | |
| 字幕 | 有时间码、术语统一、可独立理解 | |
| 录屏准备文件 | 有干净环境和备用路径 | |
| 练习与答案 | 与目标和通过标准一致 | |
| 资源清单 | 来源、版权、版本完整 | |
| 隐私说明 | 无密钥、账号和未授权个人数据 | |

## 交付预检

### 内容

- 学习目标、脚本、课件和练习一致；
- 主课来源和 `MC-ID` 没有丢失；
- 所有工具名称、界面和操作步骤已按当前版本确认；
- 示例中的数据可以公开或已经脱敏。

### 媒体

- 首屏明确主题和收益；
- 画面在移动端不依赖极小文字；
- 字幕与口播同步；
- 无声观看时仍能理解主要步骤；
- 声音、图片和外部链接都有替代方案。

### 文件

- 文件名使用 `MC-ID-主题-资源类型-版本`；
- 不使用“最终版2”一类不可追踪名称；
- `制作说明.md` 明确已完成、待制作和阻塞项；
- 可打开的文件已经实际打开或渲染检查；
- 交付包不含临时文件、缓存、密钥和个人信息。
