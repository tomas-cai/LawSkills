# 微课制作 Skill

## 定位

把已确认的微课脚本变成制作人员、讲师或平台可以使用的资源包。这里的“制作”包括素材生成、文件组织、交付前预检；如果当前环境无法真正录音、录屏或剪辑，不得假称已经生成视频，应输出明确的制作规格和待补素材清单。

本 Skill 不改变学习目标和脚本内容，不替代 `microcourse-reviewer` 的独立质量评审。

## 前置输入

读取：

- `06-微课补充包/00-微课补充地图.md`；
- 对应 `01-微课单元设计/`；
- 对应 `02-微课脚本与分镜/`；
- 主课品牌、课件、案例、模板和版权要求；
- 用户指定的平台、尺寸、格式和交付方式。

缺少脚本或脚本状态不是 `Approved`/`Final` 时，先列出阻塞，不直接进入生产。

## 生产方式选择

根据学习目标和使用场景选择一种主交付形态：

| 形态 | 适用场景 | 最小交付物 |
|---|---|---|
| 讲解视频 | 概念、案例、复习 | 画面、口播稿、字幕、文字稿 |
| 录屏演示 | 工具和固定操作 | 录屏步骤、演示环境、字幕、备用路径 |
| 交互 HTML | 判断、练习、即时反馈 | 页面、题目、答案、反馈和可访问性说明 |
| 微课课件 | 讲师带学或用户自学 | PPT/HTML、讲解稿、练习、答案 |
| 岗位支持包 | 清单、模板、快速参考 | 一页资料、示例、使用边界 |

不要为了“像视频”而把清单或模板包装成无必要的长视频。

## 制作流程

### 1. 建立资源清单

列出每个镜头或步骤需要的画面、截图、录屏、图标、音频、模板和外部引用。每项记录来源、版权状态、版本和替代方案。

### 2. 生成或整理素材

按脚本制作课件、HTML、录屏准备文件、字幕和练习。素材命名统一使用 `MC-ID`，禁止用“最终版2”“新版最终”等含糊名称。

### 3. 组装交付包

在 `06-微课补充包/03-微课交付包/MC-ID-主题/` 下组织媒体和制作文件，在 `06-微课补充包/04-微课练习与测验/` 下保存可独立复用的练习和答案：

```text
制作说明.md
课件/或页面/
录屏准备/（如适用）
字幕/MC-ID-字幕稿.vtt 或 .srt
文字稿/MC-ID-文字稿.md
练习与测验/
资源清单.md
版权与隐私说明.md
```

练习目录建议包含：

```text
04-微课练习与测验/
└── MC-ID-主题-练习与答案.md
```

无法生成的文件必须以 `待制作-` 开头，并在 `制作说明.md` 中列出阻塞原因。

### 4. 做生产预检

- 画面在手机尺寸下仍可读；
- 文字、字幕、口播和脚本一致；
- 字幕有时间码、标点和说话人信息；
- 录屏没有账号、密钥、个人信息和未授权数据；
- 链接、文件、练习答案都能打开；
- 图片、字体、音乐和案例来源可追溯；
- 文件名、版本、主课来源和 `MC-ID` 一致；
- 可提供纯文字版本，满足无声观看和无障碍需要。

## 交付边界

实际生成了 PPT、HTML、字幕或图片时，进行打开或渲染检查并记录结果。没有能力完成视频拍摄、录音或剪辑时，只交付可执行的制作包，不把“制作规格”写成“成片已完成”。

交付完成后，将整个包交给 `microcourse-reviewer` 做独立评审。
